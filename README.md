# Hackathon Board

A filterable list of open hackathons, grants and bounties (Web3, AI, Web2 and more), with prize pools,
deadlines and rough odds (paid slots ÷ expected entries).

**Live:** https://nikhil-pn.github.io/hackathon-board/

Rebuilt every morning (~06:50 IST) from Devpost, DoraHacks and a social scan, then pushed here; GitHub Pages republishes on each push.
Odds are estimates, not verified figures. Your row status (applied / skip …) is saved in your browser only.
